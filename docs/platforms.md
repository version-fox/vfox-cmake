# Supported platforms and versions

[中文](zh-CN/platforms.md) | [English](platforms.md)

## Platforms

| OS | Architectures reported by the plugin | Archive |
| --- | --- | --- |
| Linux | `amd64`, `386`, `arm64` | `.tar.gz` |
| macOS | `amd64` and universal (both are offered on Intel and Apple Silicon) | `.tar.gz` |
| Windows | `amd64`, `386`, `arm64` | `.zip` |

The plugin matches `RUNTIME.osType` and `RUNTIME.archType` against
`assets/version.json`, which is generated by `assets/get_versions.py` from the
SHA-256 files published on <https://cmake.org/files/>. A version is offered
only when the archive for the current platform exists in that file.

## Versions

Official releases from 3.0 onwards are included, plus release candidates when
CMake publishes them. The list is refreshed weekly by the `update_versions`
workflow and can be regenerated on demand from **Actions → update_versions →
Run workflow**.

Version names are the ones CMake itself prints:

```bash
vfox search cmake        # all versions for your platform
vfox install cmake@4.5.0
vfox install cmake@3.31.6
```

Pre-release versions keep their suffix, for example `4.5.0-rc1`.

## Requirements

- vfox 1.1.0 or later (Detect hook).
- A working network connection to `cmake.org` and to the jsDelivr mirror of
  `assets/version.json` used by the Available hook.
